# Legacy Frontend Archive

Esta carpeta ya no es una fuente activa de trabajo.

## Estado

- `front/` es un resguardo legado.
- El frontend canonico vive en la raiz del repositorio.
- No usar esta carpeta para `npm install`, `npm run dev`, `npm run build` ni despliegues.

## Frontend correcto

Trabajar siempre desde la raiz del repo:

```bash
npm install
npm run dev
```

## Motivo

Existian dos frontends Next compitiendo dentro del mismo repositorio, con versiones distintas y riesgo alto de editar o ejecutar la ubicacion equivocada. Esta carpeta se conserva solo por trazabilidad y consulta historica.
